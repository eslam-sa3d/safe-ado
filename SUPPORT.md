# Support

## Channels

| Channel | Use it for |
|---|---|
| [GitHub issues](https://github.com/eslam-sa3d/safe-ado/issues) | Bug reports, feature requests, questions |
| [GitHub discussions / Q&A](https://github.com/eslam-sa3d/safe-ado/discussions) (if enabled) | How-to questions and ideas |
| Marketplace *Q & A* tab | Short pre-install questions. Bugs go to GitHub issues. |
| [SECURITY.md](SECURITY.md) | Security vulnerabilities. **Do not** open a public issue. |

## What to include in a bug report

1. **Azure DevOps flavour and version:** Azure DevOps Services, or Azure DevOps Server (for example
   2022.1). On Server, give the version from *Help → About*.
2. **ScaleLane version.** It is in *Organization / Collection settings → Extensions* and in the
   Marketplace listing.
3. **Process:** Agile, Scrum, CMMI or an inherited process (name the base process).
4. **Where it happens:** the view (for example Team Planning Board) and the unit level (Portfolio,
   Large Solution, ART or Team).
5. **Steps to reproduce, what you expected, and what happened.**
6. **Browser** and version.
7. **Errors in the browser console,** if any (F12 → Console). **Remove** work item titles, names,
   e-mail addresses and URLs of your organization before posting. Issues are public.
8. For layout problems, a screenshot with sensitive data blurred.

Please do not attach exports of your SAFe configuration or work items to public issues. If we need
them, we will arrange a private channel.

| Tier | First response | Fix / workaround target | Hours |
|---|---|---|---|
| **Community** (free, GitHub issues) | Best effort, typically within 5 business days | Best effort; prioritised by impact and votes | Best effort |
| **Paid support** | TBD | TBD | TBD |

Paid support (SLA, private channel, help with on-premises installs and PI Planning onboarding) is
**to be decided**. See `docs/BUSINESS_PLAN.md`. Until then, all support is community support.

## Supported versions

Only the latest Marketplace release gets fixes. On Azure DevOps Server, upgrade by uploading the
newest VSIX. Release notes are in [CHANGELOG.md](CHANGELOG.md).
