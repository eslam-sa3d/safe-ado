# ScaleLane rollout and coaching services

ScaleLane is free. These services help an Agile PMO or Release Train Engineer get a train running
on it in Azure DevOps, on-premises (Azure DevOps Server 2022.1) or in the cloud (Azure DevOps
Services), without moving data out of Azure DevOps.

Prices are quoted per engagement. *(Owner: set list prices after the first two customer
conversations, and add your business contact below.)*

## Packages

### 1. Quick start (1–2 days, remote)

For one project and one Agile Release Train that is about to plan its first PI.

- Map the process's work item types, the area paths and the teams to the SAFe hierarchy.
- Create the PI cadence (iterations and IP iteration) and assign it to the teams.
- Set up capacity (manual or derived from Azure DevOps team capacity).
- A 90-minute walkthrough for the RTE and Product Management.

**Outcome:** a configured project, ready for PI Planning.

### 2. PI Planning launch (2–3 weeks around one PI Planning event)

Everything in Quick start, plus:

- A dry run on a test project and a check of the backlog (features sized, WSJF fields filled).
- On-call support during both days of PI Planning: Team and ART Planning Boards, dependencies,
  PI objectives with business value, ROAM risks, the confidence vote.
- A retro within 3 days, and fixes to the setup.

**Outcome:** the train's PI Planning run end to end in Azure DevOps, with objectives, risks and
dependencies in the tool.

### 3. Portfolio and governance setup (1–2 weeks)

For a PMO / LPM office with several trains or projects.

- A portfolio across projects in the same collection.
- Lean Portfolio Management: Portfolio Kanban stages and WIP limits, the Lean Business Case,
  value stream budgets and guardrails.
- Governance: SAFe roles and Business Owners, the audit log, and a backup routine.
- Reports and flow metrics for ART syncs and Inspect & Adapt.

**Outcome:** a portfolio view that leadership can use, with an audit trail.

### 4. Coaching retainer (monthly)

A fixed number of hours per month with an experienced SAFe practitioner: ART sync and PO sync
support, Inspect & Adapt facilitation, and advice on Azure DevOps process and reporting.

## On-premises and regulated organisations

All services can be delivered for Azure DevOps Server 2022.1, including environments with no
internet access: the extension is installed from a VSIX file and makes no outside calls (see
[PRIVACY.md](PRIVACY.md)).
